# EcoGestión - Sistema Web de Trazabilidad de Residuos
**Autor:** Johans Molina G.  
**Asignatura:** Proyecto de Título Iplacex

## Descripción
"EcoGestión" es un sistema web diseñado para digitalizar y automatizar la trazabilidad de residuos industriales y peligrosos. Conecta a empresas generadoras con recicladores externos mediante un registro inmutable (Audit Trail) garantizando el cumplimiento normativo medioambiental.

## Tecnologías Utilizadas (Arquitectura MVC)
- **Frontend:** HTML5, CSS3 Nativo (Mobile First, sin frameworks).
- **Backend:** PHP 8.x
- **Base de Datos:** MySQL 8.0 (Modelo Relacional normalizado en 3FN).
